# Course 4: Java Programming, Principles of Software Design

Part of Duke University's Java Programming and Software Engineering 
Fundamentals Specialization on Coursera. This course focuses on solving 
real-world problems with Java using multiple classes and interfaces, 
recognizing that software engineering is as much about logical thinking 
and design as it is about writing code, building up to a program that 
analyzes and sorts earthquake data, and a predictive text generator.

## What I learned

- Using sorting appropriately to solve problems
- Developing classes that implement the Comparable interface
- Using timing data to analyze empirical performance
- Breaking problems into multiple classes, each with their own methods
- Determining whether a class from the Java API can solve a particular problem
- Implementing programming solutions using multiple approaches and recognizing tradeoffs
- Using object-oriented concepts including interfaces and abstract classes
- Appropriately hiding implementation decisions so they aren't visible in public methods
- Recognizing the limitations of algorithms and Java programs in solving problems
- Recognizing standard Java classes and idioms, including exception handling, static methods, and the java.net/java.io packages
