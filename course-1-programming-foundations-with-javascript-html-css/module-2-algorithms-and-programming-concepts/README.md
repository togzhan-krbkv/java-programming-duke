# Module 2: Algorithms and Programming Concepts

In this module I learned the basics of programming in JavaScript: 
variables, functions, loops, and conditionals, applying them to process 
and modify images pixel by pixel, including a green screen effect.

## Topics covered

- Computational thinking and designing an algorithm using the seven step approach
- Variables, methods, and functions in JavaScript
- For loops and conditional execution
- Reading and modifying image pixel data (color channels, position)
- Debugging by thinking critically about a program's logic

## Files

- [variablesMethodsFunctions.js](./variablesMethodsFunctions.js): 
  basic experiments with variables, the SimpleImage class, and writing 
  functions (square, cube, sum, string concatenation).

- [forLoops.js](./forLoops.js): using a for loop to set every pixel in 
  a blank image to a solid color.

- [modifyingImages.js](./modifyingImages.js): three exercises: a 
  three-band color filter based on horizontal position, swapping the red 
  and green channels, and recoloring all non-white pixels.

- [advancedModifyingImages.js](./advancedModifyingImages.js): a green 
  screen effect that replaces green pixels with a background image, a 
  four-quadrant color pattern, and a function that adds a solid border 
  around an image.
