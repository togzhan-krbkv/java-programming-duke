# Course 1: Programming Foundations with JavaScript, HTML and CSS

Part of Duke University's Java Programming and Software Engineering 
Fundamentals Specialization on Coursera. This introductory course covers 
foundational programming concepts and basic web development, building up 
to an interactive website where users can upload images and apply custom 
filters.

## What I learned

- Thinking critically about how to solve a problem using programming
- Writing JavaScript programs using functions, for loops, and conditional statements
- Using HTML to construct a web page with paragraphs, divs, images, links, and lists
- Styling a web page with CSS IDs and classes
- Making a web page interactive with JavaScript, including event handlers like onClick and onChange, and input features like an image canvas, buttons, and sliders

## Development environment

This course uses CodePen for the HTML/CSS/JavaScript exercises, and the 
DukeLearnToProgram environment (with Duke's SimpleImage.js library) for 
the image processing exercises. Personal links and images from the 
original assignments have been replaced with generic public placeholders 
throughout this repository.
