# Module 1: Designing a Web Page with HTML and CSS

In this module I learned the basics of HTML and CSS by building a personal 
"My Interests" web page, starting with plain HTML structure and 
progressively adding CSS styling.

## Topics covered

- HTML structure: headings, paragraphs, text formatting, and nested tags
- Adding images and links
- Lists (ordered and unordered) and tables
- CSS basics: linking a stylesheet, class and id selectors
- Colors, borders, fonts, and text alignment in CSS

## Projects

- [ListsAndTables](./ListsAndTables): a plain HTML page using headings, 
  paragraphs, nested lists, and a table to organize the same content in 
  different formats.

- [StylingWithCSS](./StylingWithCSS): the same page extended with an 
  external CSS stylesheet, using class and id selectors to style borders, 
  colors, fonts, text alignment, and image positioning.
