# Java Programming: Duke University Specialization

Coursework, exercises, and projects from Duke University's Java Programming 
and Software Engineering Fundamentals specialization on Coursera.
Solutions here reflect my own work on course exercises, completed and shared 
after finishing the relevant course.

## About the Specialization

A 5-course sequence covering web development foundations, Java syntax, data 
structures, object-oriented design, and software engineering principles. 
Skills covered across the specialization include:

- Foundational programming concepts, HTML, CSS, and JavaScript
- Core Java syntax, control flow, and debugging
- Reading, writing, and analyzing structured data (CSV files, statistics)
- Arrays, ArrayLists, and collections (including maps)
- File I/O and data processing
- Object-oriented design: classes, interfaces, abstract classes
- Algorithm design, sorting, and empirical performance analysis
- Encryption and basic cryptography
- Predictive text generation using Markov models
- Building a recommendation system from real-world rating data

## Why this repository

I currently work as a data analyst / data engineer, primarily with PySpark, 
Python, C, C++ and SQL. I'm adding Java to my toolkit because much of the data 
engineering ecosystem is built on the JVM: Spark, Hadoop, and Kafka are 
written in Java/Scala, and understanding Java makes it easier to write 
efficient UDFs, debug JVM-level errors and stack traces, and work directly 
with the internals of the tools I use daily.

## Repository Structure

Each course folder contains its own README describing what was covered, plus 
subfolders per module with code and notes.

## Skills and Tools

**Languages**
Java, JavaScript, HTML5, CSS3

**Java concepts and API**
- Object-oriented design: classes, interfaces, abstract classes, encapsulation
- Comparable and Comparator for custom sorting logic
- equals() and hashCode() implementation
- Collections: ArrayList, HashMap, HashSet
- Arrays and multi-dimensional data
- File I/O: BufferedReader, FileReader, java.io/java.nio idioms
- XML parsing (DOM) for structured data feeds
- CSV parsing with Apache Commons CSV
- Exception handling
- Algorithm design: selection sort, bubble sort, Collections.sort, Markov models for text generation
- Empirical performance analysis and timing (System.nanoTime)
- Cryptography basics: Caesar and Vigenère ciphers, frequency analysis

**Web development**
- HTML5 semantic structure, forms, tables, lists
- CSS3: selectors, layout, animations, responsive units
- Vanilla JavaScript: functions, loops, conditionals, event-driven programming
- DOM manipulation and browser events (click, change, input)
- HTML5 Canvas API for drawing and image processing
- Client-side file upload and pixel-level image manipulation

**Tools and environments**
- BlueJ (Java IDE used throughout the specialization)
- CodePen (HTML/CSS/JS prototyping)
- DukeLearnToProgram JavaScript environment and SimpleImage.js library
